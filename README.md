# SWAAD - Restaurant Website
### DecodeLabs Internship - Project 1

A simple and responsive restaurant website for a Pakistani food brand called **SWAAD**.

Live Demo: Open `index.html` in browser

## Features

- Responsive Design - Works on mobile, tablet and desktop
- Mobile Menu - Hamburger menu for small screens
- Menu Filter - Filter by All / Desi / Fast / Sweet
- Cart Counter - Add button increases cart count
- Today's Offer - Button shows special offer
- Dark Mode - Moon button toggles dark / light mode
- Clean UI - Modern cards, navbar and hero section

## Menu Categories

- Desi: Chicken Biryani, Karahi Gosht
- Fast: Zinger Burger, Chicken Shawarma
- Sweet: Gulab Jamun, Kheer

## Tech Used

- HTML - Structure
- CSS - Styling and responsive design
- JavaScript - Filter, cart, dark mode, mobile menu

## Folder Structure

SWAAD/
- index.html - Main page
- style.css - All styling
- script.js - All functionality
- README.md - Project info

## What I Learned

- HTML structure with header, hero, menu cards, footer
- CSS Flexbox, Grid, media queries for responsive design
- JavaScript DOM, addEventListener, dataset filter

- Cart logic with counter variable
